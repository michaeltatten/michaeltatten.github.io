The Wrong Fighter Won the UFC’s Biggest Fight

The stats make the case that Conor McGregor should have won UFC 229.

Author

Michael Tatten

Published

November 13, 2026

Khabib Nurmagomedov submitted Conor McGregor in round four of the highest-selling pay-per-view in UFC history, a fight that is widely renowned as the biggest fight in the promotion’s history.

In the third round, Conor had outlanded Khabib 34-15 in significant strikes. Khabib was able to take him down in the fourth, and ultimately was able to get the finish. But in the third round, the millions of people all watching at home saw the formula for Conor to win the fight. Conor needed to keep the fight off of the ground, where he would have been able to stand and strike and give himself a real shot at victory.

I compared Conor and Khabib’s career statistics alongside 18 of the greatest fighters in the UFC’s history. I dove into how often both fighters landed significant strikes, how well they defended, and their takedown conversion percentages, throughout their careers. I opted to start with highlighting significant strikes per minute because it shows how often Conor could connect when given the proper space to strike.

Show R code 
library(tidyverse)

df <- fighter_career_stats %>%
  filter(is.finite(significant_strikes_per_minute))

df <- df %>%
  mutate(rank = min_rank(desc(significant_strikes_per_minute)))
df <- df %>%
  mutate(label = paste0("#", rank, "  ", fighter))

avg_slpm <- mean(df$significant_strikes_per_minute)

p <- ggplot(df, aes(x = significant_strikes_per_minute,
                    y = fct_reorder(label, significant_strikes_per_minute)))

p <- p + geom_col(aes(fill = highlight), width = 0.65)

p <- p + geom_vline(xintercept = avg_slpm, linetype = "dashed", color = "#51575E")

p <- p + geom_text(aes(label = round(significant_strikes_per_minute, 2)),
                   hjust = -0.2, size = 3.8, color = "#30343A")

p <- p + annotate("label",
                  x = avg_slpm,
                  y = nrow(df) + 0.8,
                  label = paste("Group average", round(avg_slpm, 2)),
                  size = 3.2, color = "#51575E", fill = "white")

p <- p + scale_fill_manual(values = fighter_colors)
p <- p + scale_x_continuous(expand = expansion(mult = c(0, 0.15)))
p <- p + scale_y_discrete(expand = expansion(add = c(0.5, 1.2)))

p <- p + labs(title = "Conor's Best Shot Was on the Feet",
              subtitle = paste("Career significant strikes landed per minute among", nrow(df), "selected UFC fighters."),
              x = "Significant strikes landed per minute",
              y = NULL,
              caption = chart_credit)

p <- p + clean_theme
p <- p + theme(panel.grid.major.y = element_blank())

print_clean_chart(p)

Conor ranks ahead of Khabib in significant strikes landed per minute, and is among the ranks of some of the greatest to ever fight for the promotion. His most clear path to victory versus Khabib was keeping the fight standing, and making Khabib duke it up with him. He is one of the most dangerous strikers in UFC history and would have been able to keep Khabib fighting at his pace. We saw this in the third round when the undefeated Khabib looked the most beatable he had looked up until that point in his career. But keeping the fight like this was the hard part.

The next aspect that was going to be key to dive into was strike and takedown defense. This data is crucial to see who was harder to hit and who was harder to takedown throughout their careers.

Show R code 
df_def <- fighter_career_stats %>%
  filter(between(strike_defense, 0, 100), between(takedown_defense, 0, 100))

avg_strike_def <- mean(df_def$strike_defense)
avg_td_def <- mean(df_def$takedown_defense)

featured_df <- df_def %>%
  filter(fighter %in% featured_fighters)

featured_df <- featured_df %>%
  mutate(short_name = if_else(fighter == "Conor McGregor", "Conor", "Khabib"))
featured_df <- featured_df %>%
  mutate(label = paste0(short_name, "\n", strike_defense, "% strikes | ", takedown_defense, "% takedowns"))
featured_df <- featured_df %>%
  mutate(label_y = takedown_defense + if_else(short_name == "Conor", -8, 8))

other_df <- filter(df_def, highlight == "Other fighters")

p2 <- ggplot(df_def, aes(x = strike_defense, y = takedown_defense))

p2 <- p2 + geom_vline(xintercept = avg_strike_def, linetype = "dashed", color = "#727980")
p2 <- p2 + geom_hline(yintercept = avg_td_def, linetype = "dashed", color = "#727980")

p2 <- p2 + geom_point(data = other_df,
                      color = fighter_colors[["Other fighters"]], size = 2.8)
p2 <- p2 + geom_point(data = featured_df, aes(color = fighter), size = 4.2)

p2 <- p2 + geom_text(data = featured_df,
                     aes(y = label_y, label = label, color = fighter),
                     fontface = "bold", size = 3.9, lineheight = 0.95)

p2 <- p2 + annotate("label", x = avg_strike_def, y = Inf, vjust = 1.2,
                    label = paste0("Avg. strike defense ", round(avg_strike_def, 1), "%"),
                    size = 3.1, color = "#51575E", fill = "white")
p2 <- p2 + annotate("label", x = -Inf, y = avg_td_def, hjust = -0.05,
                    label = paste0("Avg. takedown defense ", round(avg_td_def, 1), "%"),
                    size = 3.1, color = "#51575E", fill = "white")

p2 <- p2 + scale_color_manual(values = fighter_colors)
p2 <- p2 + scale_x_continuous(labels = percent_label, expand = expansion(mult = c(0.17, 0.13)))
p2 <- p2 + scale_y_continuous(labels = percent_label, expand = expansion(mult = c(0.10, 0.17)))

p2 <- p2 + labs(title = "Khabib Was Harder to Hit and Harder to Take Down",
                subtitle = "Each dot is one fighter. Dashed lines mark the group averages.",
                x = "Significant strikes defended (%)",
                y = "Takedown attempts stopped (%)",
                caption = chart_credit)

p2 <- p2 + clean_theme

print_clean_chart(p2)

Throughout their careers, Khabib defended 65% of significant strikes and 84% of takedown attempts, while Conor defended 54% and 67%. The dashed lines show the group averages for both categories.

I expected Khabib to be harder to takedown, he has been his entire career. I mean, he literally trains with bears in preparation for fights. But the striking defense gap is what caught my eye. Even when Conor got the stand-up and strike fight like he wanted, he still had to land against someone who made opponents miss more often than he did.

I finished with takedown accuracy to ultimately determine which fighter was more likely to get an opponent down to the ground when they went for it.

library(grid)

df_waffle <- fighter_career_stats %>%
  filter(between(takedown_accuracy, 0, 100))

df_waffle <- df_waffle %>%
  mutate(rank = min_rank(desc(takedown_accuracy)),
         total_fighters = n())

df_waffle <- df_waffle %>%
  filter(fighter %in% featured_fighters)

df_waffle <- df_waffle %>%
  mutate(fighter = factor(fighter, levels = featured_fighters))

df_waffle <- df_waffle %>%
  mutate(panel_label = fct_reorder(
    paste0(fighter, "\n", takedown_accuracy, "% | #", rank, " of ", total_fighters),
    as.numeric(fighter)))

df_waffle <- df_waffle %>%
  uncount(100, .id = "sq")

df_waffle <- df_waffle %>%
  mutate(col = (sq - 1) %% 10 + 1,
         row = 10 - (sq - 1) %/% 10)

df_waffle <- df_waffle %>%
  mutate(outcome = if_else(sq <= round(takedown_accuracy), as.character(fighter), "Missed"))

p3 <- ggplot(df_waffle, aes(x = col, y = row, fill = outcome))

p3 <- p3 + geom_tile(width = 0.88, height = 0.88)
p3 <- p3 + facet_wrap(~ panel_label, nrow = 1)
p3 <- p3 + coord_equal()
p3 <- p3 + scale_fill_manual(values = fighter_colors)

p3 <- p3 + labs(title = "Conor Had the Edge in Khabib's Game",
                subtitle = "Share of career takedown attempts landed. Each square is one percentage point.",
                x = NULL,
                y = NULL,
                caption = chart_credit)

p3 <- p3 + clean_theme
p3 <- p3 + theme(axis.text = element_blank(),
                 axis.ticks = element_blank(),
                 panel.grid.major = element_blank(),
                 panel.spacing = unit(1.5, "lines"),
                 plot.title = element_text(color = "transparent"),
                 plot.subtitle = element_text(color = "transparent"),
                 plot.caption = element_text(color = "transparent"))

print_clean_chart(p3)

x_left <- unit(22, "pt")
y_top <- unit(1, "npc")

grid.text(p3$labels$title,
          x = x_left, y = y_top - unit(22, "pt"),
          just = c("left", "top"),
          gp = gpar(fontfamily = headline_font, fontface = "bold", fontsize = 21, col = "#202124"))

grid.text(p3$labels$subtitle,
          x = x_left, y = y_top - unit(50, "pt"),
          just = c("left", "top"),
                    gp = gpar(fontsize = 10, col = "#51575E"))

Conor landed 55% of his career takedown attempts to Khabib’s 48%. This ranked Conor eighth and Khabib eleventh among 20 of the greatest UFC fighters ever. The seven extra red squares show how much Conor was able to convert when he attempted a takedown.

Khabib still averaged 5.32 takedowns per 15 minutes to Conor’s 0.70. Conor was more efficient with his takedowns, but Khabib got opponents down more than seven times as often.

This was ultimately the difference that mattered when looking back at this fight. Conor showed the concept of being able to win in the third with his stand-and-bang approach. Khabib’s wrestling background gave him a way to put constant pressure on Conor, and ultimately led to a takedown which led to a submission.

I whole-heartedly believe if there would have been a rematch of this fight, while both fighters were still in the primes of their careers, that Conor would have kept it standing and made Khabib play his game.
